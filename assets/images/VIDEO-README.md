# Video Background Instructions

## Download a City Skyline Video

1. Go to **Pixabay.com** or **Pexels.com**
2. Search for "city skyline" or "urban timelapse"
3. Download a free HD video (MP4 format, 1920x1080 recommended)

### Recommended Videos:
- **Pixabay**: https://pixabay.com/videos/city-skyline-urban-night-24502/
- **Pexels**: https://www.pexels.com/video/time-lapse-of-city-traffic-at-night-854912/

## Installation

1. Rename the downloaded file to `city-skyline.mp4`
2. Place it in `/opt/data/labwyze.com/assets/images/`
3. The video will automatically display as background on the homepage

## Fallback

The original `toronto.jpg` image remains as a fallback for browsers that don't support video or if the video file is missing.
